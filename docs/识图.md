# 识图

安装 `dsh-image-pathify` 后，Web **设置 → 插件** 里会多一张 **识图** 卡片，排在「网页搜索」下面。交互和终端 / Agent 循环 / 网页搜索相同：改完点保存，未改时底部按钮是灰色。主题跟随宿主 `--dsw-alias-*` token，文案跟随系统中英文。

## 设置项

| 字段                     | 说明                                                                                                |
| ------------------------ | --------------------------------------------------------------------------------------------------- |
| API Key                  | 视觉接口的 Bearer token。不写入设置文件，保存在 `$DSH_HOME/.credentials.yaml`。留空保存表示不修改。 |
| 识图模型                 | 默认 `qwen-vl-plus`。留空用默认。                                                                   |
| 接口地址                 | 任何 OpenAI 兼容格式 URL，留空则使用默认地址。                                                      |
| 路径前缀                 | 发给不能看图的模型前，每张图变成 `{前缀}{绝对路径}`。通常无需修改。                                 |
| 允许给不能看图的模型发图 | 对应 `relaxAdmission`。关闭后按模型能力拒绝贴图。                                                   |
| 放行的模型               | `provider` + `model` 名单。空 = 全部放行。                                                          |

点 **保存** 后立即生效，不用重启。非密钥字段走本插件自己的 Remote（`imagePathify/getSettings`、`imagePathify/updateSettings`）；密钥走宿主的 credentials 领域，和「网页搜索」同一份 `$DSH_HOME/.credentials.yaml`。设置文件里的 `apiKeyEnv` 是引用名，默认 `IMAGE_PATHIFY_API_KEY`——和网页搜索的 `DEEPSEEK_API_KEY` 一样，没改过就不会出现在 YAML 里。

任何 OpenAI 兼容的视觉模型都可以：把地址和模型改成你的服务即可。

## 工具与策略

模型侧只多一个工具：

- **`analyze_image`**
  - `image`（必填）：本地绝对路径，或 `http(s)` 图片 URL。不要带路径前缀。
  - `prompt`（可选）：关于图片的问题。默认「请详细描述这张图片的内容。」

系统提示会告诉模型：看到前缀开头的路径时调用 `analyze_image`，不要对不能看图的模型调用 `read_image`。

如果模型仍然调用 `read_image`，且当前路由没有声明 `image` 输入，插件会在 `tools/pre-execute` 拒绝这次调用，并在原因里写明改用 `analyze_image`。已经能看图的模型不受影响。

## 请求格式

识图请求与 OpenAI compatible-mode 一致：

```
POST {visionBaseUrl}/chat/completions
Authorization: Bearer {apiKey}
Content-Type: application/json

{
  "model": "{visionModel}",
  "messages": [{
    "role": "user",
    "content": [
      { "type": "image_url", "image_url": { "url": "<data URL 或 http URL>" } },
      { "type": "text", "text": "<prompt>" }
    ]
  }],
  "stream": false,
  "max_tokens": 1024
}
```

本地文件会先读成 `data:image/<subtype>;base64,...`。贴进聊天的图片已经由 dsh 附件库落盘，不使用剪贴板回退。
